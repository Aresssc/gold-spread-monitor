# 黄金境内外价差监控看板

监控境内黄金（沪金期货 / SGE 现货）与境外黄金（COMEX 期货 / 伦敦金现）× 人民币汇率的价差，
全部免费公开数据源（新浪财经、东方财富、上金所官网、欧央行参考汇率），纯标准库 Python，无第三方依赖。

## 页面

| 页面 | 内容 |
|---|---|
| [index.html](./index.html) | 双对监控报告：期货对（沪金 vs COMEX）+ 现货对（SGE vs 伦敦金现），含历史分位 |
| [micro.html](./micro.html) | 5 分钟微观研究：三腿同刻对齐、均值/σ/σ 位置、±1.5σ 开仓提示、实时三腿报价 |
| [strategy.html](./strategy.html) | 日线级均值回归策略报告（回测：点位、止盈止损、回归用时） |

## 更新机制（GitHub Actions）

工作流 `update.yml` 定时运行（北京时间）：

- 日盘 09:10 / 10:10 / 11:10 / 13:10 / 14:10（周一至周五）
- 夜盘 21:10 / 22:10 / 23:10 / 00:10 / 01:10 / 02:10（周日至周五）

脚本内置沪金交易时段守卫：**非交易时段（含小节休息外的时间与节假日）自动跳过，数据暂停更新**。
每次运行后重新部署 GitHub Pages，并提交 5 分钟样本归档（`data5m/archive_5m.jsonl`，用于窗口自然延长）。

## 口径说明

- 价差 = 境内价（元/克）− 境外价 ÷ 31.1035 × 汇率；正 = 境内溢价，负 = 境内折价
- 5 分钟口径汇率腿使用离岸 USDCNH（在岸无免费分钟历史），与在岸偏差通常 < 0.3%
- 日线口径存在收盘时点错位（境外收盘为北京时间次日凌晨），5 分钟同刻口径更接近可执行信号
- 免费数据源分钟级保留期有限（外盘 5 分钟约 5 个交易日），窗口随归档逐日延长
